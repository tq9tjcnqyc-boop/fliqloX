# FliqloX

翻转时钟的网页版。与原版 Fliqlo 同一套视觉，零依赖。

## 用法

打开 `index.html` 即可，或者访问 GitHub Pages 地址。

| 操作 | 效果 |
|---|---|
| 双击 | 进入 / 退出全屏 |
| `F` | 切换全屏 |
| `Esc` | 退出全屏 |

## URL 参数

可以拼参数定制，方便分享特定设置的链接：

```
?tf=1      24 小时制（补零）
?tf=2      24 小时制（不补零）
?sc=80     大小，50–100
?br=70     亮度，25–100
?bg=0      不显示深色底
?bgb=200   卡片底色亮度，0–400（100 = 原版原值，0 = 纯黑，数值越大卡片越灰）
?bc=0      关闭亮度调节（忽略 br，亮度强制回满 100%）
?sec=1     右下角显示秒
?date=1    左下角显示日期
?week=1    显示星期
```

`tf` 默认 0（12 小时制）。效果差别：

```
tf=0   09:41 → 9:41 AM
tf=1   09:41 → 09:41
tf=2   09:41 → 9:41
```

例如：`?tf=1&sec=1` —— 24 小时制 + 显示秒。

## 实现

单个自包含的 HTML 文件，约 36 KB（gzip 后约 12 KB）：

- 样式表与数字字形与原版一致，内嵌在页面里
- 时钟逻辑用原生 JavaScript 重写，不依赖任何库
- 字体以 `data:` URL 内嵌，无额外请求
